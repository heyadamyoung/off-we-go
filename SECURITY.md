# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature on this repository instead.

Include the affected component, reproduction steps, expected impact, and any suggested mitigation. Do not access other people's data, disrupt the hosted service, or retain sensitive information while researching a report.

Supported security fixes are applied to the current `main` branch. There are no separately supported release branches yet.
