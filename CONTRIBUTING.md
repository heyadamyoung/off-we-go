# Contributing to Off We Go

Thank you for helping improve Off We Go.

## Development

1. Fork the repository and create a focused branch.
2. From `app/`, install dependencies with `pnpm install`.
3. Make the smallest coherent change and add tests for behavior changes.
4. Run `pnpm test:unit`, `pnpm test:server`, and `pnpm build`.
5. Open a pull request explaining the user impact and verification performed.

Never commit credentials, private trip data, production database exports, Apple signing keys, or deployment secrets. Use synthetic data in tests and screenshots.
